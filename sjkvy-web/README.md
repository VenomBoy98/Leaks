# SJKVY Web

One React + TypeScript + Vite + Tailwind application, consolidated from Stitch exports.
The Stitch design is the canonical visual source and is preserved verbatim.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build
npm run typecheck
npm run convert    # regenerate page content from ../_stitch_raw (after new Stitch batches)
```

Pages: Home, About, Programs, Campus, Admission, FAQ, Certificate Verification, Contact,
Login. See `CONSOLIDATION_AUDIT.md` for the merge report and `PROJECT_MEMORY.md` before
adding future batches. Frontend-only — no backend wiring in this phase.
